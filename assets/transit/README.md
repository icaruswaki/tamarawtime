# Transit reference data

These files are imported from the supplied Flutter app. The rail graph and fare
reference tables are time-limited reviewed data, not live service information.
See `OSM_DATA_LICENSE.md`, `sakay_gtfs_LICENSE.md`, and the app's
`TRANSIT_PLANNER.md` for provenance and limits. Historical Sakay records are
reference-only and are never used to calculate current journeys.
