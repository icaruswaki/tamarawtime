# Tamaraw Time v7 motion

- Page slide/fade: ~340 ms; staggered cards: ~420 ms.
- Interactive theme selection, button hover/tap and card lift.
- Tutorial dashboard progress bar, route drawing, GPS pulse, selected-AM highlight, scene changes and color samples.
- Live route polyline has fade-in; current GPS dot pulses.
- Every animation is disabled or reduced for users with `prefers-reduced-motion: reduce`.

All effects use CSS; there is no animation dependency or animation-specific API key.
